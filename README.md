# Background Remover Bot

Телеграм-бот на **aiogram 3**, который удаляет фон с присланных фотографий с помощью модели **rembg (u2netp)**.

## Возможности

- Принимает изображения как фото и как документ (JPG, PNG, WEBP)
- Удаляет фон с помощью нейросети `u2netp` (библиотека [rembg](https://github.com/danielgatis/rembg))
- Модель загружается один раз при старте и переиспользуется для всех запросов
- Обработка изображения выполняется в отдельном потоке (`asyncio.to_thread`), чтобы не блокировать event loop бота
- Показывает статусное сообщение «Обрабатываю фото...» на время обработки
- Отправляет результат обратно документом в формате PNG с прозрачным фоном
- Обрабатывает ошибки при некорректных или повреждённых файлах

## Стек технологий

- Python 3.10+
- [aiogram](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- [rembg](https://github.com/danielgatis/rembg) — удаление фона на основе ONNX-моделей
- [python-dotenv](https://pypi.org/project/python-dotenv/) — загрузка переменных окружения из `.env`

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/buligar/background_remover_bot.git
   cd background_remover_bot
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   Если файла `requirements.txt` ещё нет, минимальный набор зависимостей:

   ```bash
   pip install aiogram rembg python-dotenv
   ```

4. Создайте файл `.env` в корне проекта и укажите токен бота, полученный у [@BotFather](https://t.me/BotFather):

   ```env
   BOT_TOKEN=ваш_токен_бота
   ```

## Запуск

```bash
python main.py
```

При первом запуске `rembg` автоматически скачает веса модели `u2netp` (несколько мегабайт) и сохранит их в кэш `~/.u2net`.

## Использование

1. Найдите бота в Telegram и отправьте `/start`.
2. Пришлите фотографию (как фото или файлом в формате JPG/PNG/WEBP).
3. Дождитесь сообщения об обработке — бот пришлёт файл `no_background.png` с удалённым фоном.

## Структура проекта

```
background_remover_bot/
```
